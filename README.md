# NoteVault-CLI 📝

A lightweight, robust, and file-backed command-line note-taking application built in **Java**. `NoteVault-CLI` allows users to quickly create, view, search, and manage notes right from their terminal using clean Object-Oriented principles and Java File I/O.

---

## Features

- **Add Notes**: Create and persistently save notes with unique titles and detailed content.
- **View All Notes**: Display a neatly formatted, indexed list of all stored entries in your vault.
- **Search Notes**: Dynamically search through your notes using keyword matching on titles.
- **Clear Vault**: Wipe or reset the note vault when a clean slate is needed.
- **Persistent Storage**: Automatically saves and reads notes from a local `vault_notes.txt` file so your data remains safe between sessions.
